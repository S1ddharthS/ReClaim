Software Engineering Assignment – Jira & Scrum
Assignment Title:
Agile Software Development using Scrum and Jira
Objective:
To understand and practically implement the Scrum framework using Jira by creating a 
software project, preparing a Product Backlog, planning a Sprint, assigning tasks, tracking 
progress, and documenting the Sprint outcome.
Question
Create and manage a software project using Jira by following the Scrum framework.
You will be assigned one unique software system from the list provided by the faculty. 
Using Jira, create a Scrum project and demonstrate the complete workflow from Product 
Backlog → Sprint Planning → Task Execution → Progress Tracking → Sprint 
Completion.
Your Jira project must contain:
1. Project creation using the Scrum framework.
2. A suitable Product Backlog containing at least 10 user stories/tasks.
3. Each user story should contain:
o User story description
o Priority
o Story points
o Acceptance criteria
4. Create at least 2 Sprints.
5. Move selected backlog items into Sprint 1 and perform Sprint Planning.
6. Assign issues to team members.
7. Update issue status as work progresses, such as:
To Do → In Progress → Done
8. Create at least one Bug and track its resolution.
9. Complete Sprint 1 and record the Sprint result.
10. Create Sprint 2 using the remaining backlog items.
11. Show the Jira Scrum Board and progress of your project.
12. Submit screenshots as evidence of your work.
🔴 Important: Individualized Work
To ensure that no two students have the same output:
 Each student/team will be given a different software project scenario.
 Students must create their own user stories, priorities, story points, task 
assignments and sprint planning.
 Copying user stories, screenshots or Jira boards from another student is not 
allowed.
 Screenshots must clearly show the student's own Jira project/board.

 Screenshot Requirement

7. Bug created and its status

10. Final project dashboard/report
Each screenshot must contain the student's Jira project name/key or other identifiable 
project information.
